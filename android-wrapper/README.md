# Eden Desk Android Test Wrapper

This project packages the live Eden Desk web application at `https://eden-desk.com` into an installable Android test APK.

Included in this test build:

- Secure HTTPS WebView shell
- JavaScript, cookies and browser storage support
- File upload picker
- HTTP and browser-generated Blob/PDF downloads
- Android Downloads/Eden Desk output folder
- Back navigation
- Offline error screen
- Black-and-white application shell

This test package does not yet contain production Huawei IAP credentials or a production signing key.
